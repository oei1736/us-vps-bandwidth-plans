## 美国大流量 VPS 应该先看什么

### 1. 流量配额和端口速度不是一回事

端口速度代表服务器网络接口理论上可以达到的速率，月流量则决定你一个计费周期内能传输多少数据。

举个简单例子：

- 1Gbps 端口不等于每月无限流量；
- 1 TB/月更适合访问量中等的网站、开发环境或轻量文件服务；
- 3–6 TB/月更适合图片较多的网站、多个项目共用、备份同步或较高访问量的应用；
- 如果业务持续提供大型文件下载，单看端口速度很容易高估实际承载能力。
